# Capability registry

ToolRegistry and AgentRegistry are the execution allowlists. CapabilityRegistry reports actual schemas, permission metadata and measured mission history. On Windows only, experimental app/site adapters join the four workspace/system tools.

The searchable expansion/Omega catalogs are reference metadata. Adding a row never installs code, grants a permission or creates an executable tool. Status is scoped evidence, not proof that external hardware/accounts are available. Generate matrices with `python scripts/sync_roadmap.py` and check with `--check`.
